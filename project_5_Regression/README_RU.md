### Описание проекта

Предстоит решить задачу машинного обучения, направленную на автоматизацию бизнес процессов. Построить модель, которая будет предсказывать общую продолжительность поездки такси в Нью-Йорке

**Основные цели проекта:**
1. Сформировать набор данных на основе нескольких источников информации
2. Спроектировать новые признаки с помощью Feature Engineering и выявить наиболее значимые при построении модели
3. Исследовать предоставленные данные и выявить закономерности
4. Построить несколько моделей и выбрать из них наилучшую по заданной метрике
5. Спроектировать процесс предсказания времени длительности поездки для новых данных

Загрузить свое решение на платформу Kaggle, тем самым поучаствовав в соревновании.
Отработать навыки работы с несколькими источниками данных, генерации признаков, разведывательного анализа и визуализации данных, отбора признаков и, конечно же, построения моделей машинного обучения.

:arrow_up:[к оглавлению](_)

**Что решаем** 

**Бизнес-задача:** определить характеристики и с их помощью спрогнозировать длительность поездки такси.

**Техническая задача как для специалиста в Data Science:** построить модель машинного обучения, которая на основе предложенных характеристик клиента будет предсказывать числовой признак - время поездки такси. То есть решить задачу регрессии.


### Краткая информация о данных

* Тренировочный датасет, с информацией о поездках в Нью-Йорке;
* Датасет с погодой и погодными условиями для того временного отрезка, когда совершались поездки;
* Датасет с информацией о официальных праздничных днях в США в тот временный период;
* Подготовленный датасет с информацией из OSRM API; 
* Подготовленные датасет для тестовой выборки + информация из OSRM API для тестовых данных;

### Этапы работы над проектом  

* 1 этап - Знакомство с данными, базовый анализ и расширенние данных

* 2 этап - Разведывательный анализ (EDA)

* 3 этап - Отбор и преобразование признаков

* 4 этап - Решение задачи регрессии: линейная регрессия и деревья решений

* 5 этап - Решение задачи регрессии: ансамблевые методы и построение прогноза

### Результаты:  

Итоги проекта: 

* Произвели базовый анализ, добавили новые данные в наш исходный датасет;
* Изучили числовые и категориальные признаки на взаимосвязи, построили визуалиации, посмотрели на влияние разных признаков на целевую переменную;
* Преобразовали все категориальные признаки, подготовили данные к обучению;
* Произвели отбор наиболее важных признаков, отобрали 25 наиважнейших, которые далее использовали для построения моделей;
* Построили и обучили модели регрессии, использовали модели линейной регрессии, регресси на полиноминальных признаках, модели с регуляризацией L2;
* Использовали более сложные модели, такие как деревья решений, градиентный бустинг и модель экстремального градиентного бустинга;
* Выбрали наиболее эффективную модель, в нашем случае это ансамбль: Градиентный бустинг, сделали предсказания на тестовой выборке; 
* Загрузили файл Submission в соревнование на Kaggle.com, c результатом RMSLE: **Private Score 0.40032**; **Public Score 0.40348**
* Залогировали результаты в Comet.ml (https://www.comet.com/apiona13/project-regression/e33ca42f464847a180126c1e0f6963f6)
