## 1. Описание проекта  

В одной из крупных торговых сетей возникла задача — минимизировать случаи, когда товар поступает в магазин, но не продаётся должным образом. Такие ситуации означают, что распределение товара было выполнено неэффективно.  

**Бизнес-цель:**  
Увеличить долю продаж продукта в первые недели после его поступления, предсказывая, станет ли товар бестселлером в конкретной локации.

**Техническая задача:**  
Создать модель бинарной классификации, которая будет предсказывать, будет ли конкретный товар в конкретном магазине бестселлером.

## 2. Датасеты и признаки  

- `train.csv` – основной датасет с целевой переменной `Is_Bestseller`. Коммерческие показатели удалены для предотвращения утечки данных.

## 3. Этапы работы  

### 1. Чтение и Объединение данных

- Присоединение всех источников к основному набору по ключевым полям.  
- Первичный анализ данных

### 2. Очистка и предобработка 

- Предобработка данных
- Приведение типов, обработка пропусков.

### 3. EDA и анализ классов 

- Проверка сбалансированности классов
- Визуализация распределений, поиск взаимосвязей
- Проверка статистической значимости взаимосвязей

### 4. Создание и трансформация признаков  

- Инженерия и трансформация признаков 
- Категориальное кодирование: `LabelEncoder`, `BinaryEncoder`, `get_dummies`.  
- Корреляционный анализ и удаление мультиколлинеарных признаков.
- Масштабирование данных: `StandardScaler`

### 5. Моделирование

- Использование моделей для решения задачи классификации:
    * `Logistic Regression`
    * `Decision Tree Classifier`
    * `Random Forest Classifier`
    * `Gradient Boosting Classifier`
    * `XGBoosting Classifier`
    * `CatBoost Classifier`
    * `Stacking`
    * `Voting Classifier`
- Использование модели `CatBoost Classifier` как основной.  
- Балансировка классов через `SMOTE`.
- Селекция признаков с использованием `Feature Importance` и `PCA`
- Подбор оптимального порога вероятности (`Recall ≥ 0.63`) для модели `CatBoost Classifier`  
- Оценка по модели по метрикам `Precision`, `Recall`, `F1-Score` для класса 1. Кросс-валидация финальной модели

### 6. Pipeline и продакшн  

- Реализация кастомного пайплайна.  
- Сериализация модели через `joblib`.  

---

## 4. Результаты  

- Модель `CatBoostClassifier` успешно обучена на сбалансированных данных  
- Добились требуемого значения `Recall` без значительного ущерба `Precision`, прирост по сравнению с Baseline более чем в 2.5 раза
- По всем трем метрикам достигли значения в 0.63 для класса 1, при отсутствии спадка чувствительности к классу 0 (значение по всем трем метрикам 0.92)
- Модель сохранена в пайплайн, пайплайн обучен и протестирован на тестовых данных
